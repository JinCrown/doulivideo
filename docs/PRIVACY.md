# 隐私与本地数据

本仓库只提供软件介绍、截图与安装包，不接收或保存你的平台登录凭据。

- B站与抖音账号分别登录，登录状态保存在本机；应用功能直接与对应平台通信。
- 播放、收藏、评论、消息等操作涉及的平台请求受对应账号权限和平台规则约束。
- 收听历史、续听进度、下载和缓存保存在本机，可在对应平台「我的」中查看和管理。
- 收听统计按实际播放时间累计，倍速不增加时长；周、月、年和累计统计可在登录卡片的收听统计入口查看。
- 自动预加载会使用网络和本地缓存，移动网络预加载默认关闭，可自行选择。
- 数据导出文件可能包含你的个人收听记录，请只保存或传给自己信任的设备。
- 卸载或清除应用数据可能导致本地记录丢失，操作前请先导出需要保留的数据。

反馈问题时，请不要公开 Cookie、令牌、登录二维码、私信内容、完整账号资料或未脱敏日志。
如确需展示页面，请先遮盖个人信息。
